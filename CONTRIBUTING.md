# Contributing to Journai

Thanks for helping. Bug reports and pull requests are welcome.

## Before you open a pull request

- Run `flutter analyze` and `flutter test` and make sure both pass.
- Keep changes focused. One pull request per fix or feature.
- Report security issues privately as described in [SECURITY.md](SECURITY.md), not as a public issue.
